# Sample transmission mid-infrared spectra of peat samples

Sample transmission mid-infrared spectra of peat samples from the
'redoxpeat' package.

## Usage

``` r
irpeat_sample_data
```

## Format

An [`ir`](https://henningte.github.io/ir/reference/ir_new_ir.html)
object with 59 samples. See `?redoxpeat::d_mir` for additional
information.
